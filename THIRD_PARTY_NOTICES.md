## 3. Competition-provided materials: referenced, not copied

The competition's rules, as relayed by the repository author from the official Rules (§4(b)), forbid redistributing Competition Data to nonparticipants and define it to include prototype or executable code supplied through the competition website. **This repository therefore contains no competition-supplied file**; it links to the official sources instead. Public sharing of the participants' *own* code is a separate matter: §6(b) of the same rules permits it, with an OSI-approved licence and with sharing that also goes through the competition's Kaggle discussion forum or associated notebooks. That is why the original code here is Apache-2.0 and is also published as a Kaggle dataset, a Kaggle notebook and a discussion post.

### Adapted from the official starter notebook (Apache-2.0)

`kaggle/copy-test-lora.ipynb` adapts set-up code from **"Getting Started - Gemma 4 Developer Agent"** by **Ryan Holbrook**, <https://www.kaggle.com/code/ryanholbrook/getting-started-gemma-4-developer-agent>, which is licensed under the **Apache License 2.0**. (That is the licence stated on the notebook's Kaggle page, as established by the repository author. The notebook's source contains no licence text, and the page's licence field is not exposed by the Kaggle command-line tool, so it was not re-read independently here.)

| what | where in our notebook |
|---|---|
| offline installation of the competition wheels, the environment variables, the cutlass `.pth` workaround and the wheel-name repair | cell 1: adapted, not copied wholesale; the cell's own comment says it follows the supplied notebook |
| the pattern for stopping a server left over from an earlier cell | cell 3: a few lines match |

The notebook is shipped **exactly as executed and unmodified**, so the notice is not inside the cell; it is here and in the description of the public Kaggle notebook. The rest of the notebook (adapter lookup, LoRA-enabled server arguments, the paired 18-input comparison, the evidence bundle) is original. The competition wheelhouse and the model that the starter notebook uses are inputs of our notebook as well; they are referenced, not copied. A copy of the Apache-2.0 licence is in `LICENSE`.
